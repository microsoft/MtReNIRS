# Final result images

These static images were regenerated by reading each dataset's raw embedded
montage or separate local sidecar, passing the adapter output through the public
`montage-align` package, and comparing every assigned slot with the prior local
mapping logic. All 12 comparisons matched exactly.

- `montage_pretraining_overview.png`: a color-coded overlay of all 12 aligned
	montages beside 12 dataset-specific mini heads on the same Standard 1005 grid.
- `montage_alignment_examples.png`: representative final alignment strategies.
- Twelve `montage_<dataset>.png` files: final rendered examples for every
	pretraining montage used in the study.

The third-party datasets' original or transformed montage CSV/TSV files,
optode coordinates, per-channel mappings, and intermediate geometry snapshots
are intentionally not distributed. These images are documentation examples,
not package inputs and not sufficient to reconstruct the source montages.
