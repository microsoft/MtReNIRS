# Security

Microsoft takes the security of its software products and services seriously,
including source code repositories managed through its GitHub organizations.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Report them privately to the Microsoft Security Response Center (MSRC):

- [Submit a vulnerability report](https://msrc.microsoft.com/create-report)
- Email: [secure@microsoft.com](mailto:secure@microsoft.com)

Include the repository name, the affected component or version, steps to
reproduce the issue, its security impact, and any suggested mitigation. Do not
include sensitive information in a public issue.

Reports are handled according to the
[Microsoft Security Response Center policies](https://www.microsoft.com/msrc/).

## Supported versions

Security fixes are applied to the current release and the repository's default
branch. Users should update to the latest available version before reporting a
resolved issue.
